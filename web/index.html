Modelo y límites explícitos

La misma filosofía que Orbitae: cada identidad termodinámica se comprueba en vivo, y cada desviación frente a la realidad se declara en una tabla. Nada se esconde detrás de una interpolación bonita.

Energía de mezcla

gmix = RT [x ln x + (1−x) ln(1−x)] + x(1−x)[L₀ + L₁(2x−1)]

Solución regular de Bragg–Williams con el primer término de Redlich–Kister para asimetría. G = H − TS en cada fase.

Tangente común

μAα = μAL ,  μBα = μBL

Envolvente convexa sobre las curvas G(x) + refinamiento de Newton 2×2. Residual típico < 10⁻⁷ J/mol.

Regla de la palanca

fα = (xL − x₀) / (xL − xα)

Fracciones molares de cada fase en equilibrio, conservando la materia: fα + fL = 1 exactamente.

Espinodal y punto crítico

∂²g/∂x² = 0  ⇒  Tc = Ω / 2R

La frontera de inestabilidad intrínseca. Entre binodal y espinodal la fase es metaestable: nucleación, no descomposición espontánea.

Clausius–Clapeyron

dP/dT = L / (T Δv)

Con la ecuación de Wagner (IAPWS) para el vapor del agua: L̂ = RT² · d ln P/dT reproduce los 40.66 kJ/mol de ebullición.

Regla de fases de Gibbs

F = C − P + 2

Condensada a P fija: F = C − P + 1. En el eutéctico coexisten 3 fases → F = 0: un punto invariante, y el visor lo marca.

EL REPOSITORIO · PUBLICADO

Phasemap v0.4.0

Lo que empezó como propuesta es hoy un repositorio real y verificado: núcleo stdlib, 79 tests, motor multifase con eutectoide, dos visores en vivo bilingües ES/EN, datos con límites declarados y citación Zenodo. AGPL-3.0.

Estado: Fases 1–12 completadas

Núcleo: envolvente convexa + Newton sobre potenciales químicos, en Python stdlib (sin numpy/scipy). 79 tests analíticos en CI.

Visores: este (2 fases · Pb–Sn, Cu–Ni, Ag–Cu, agua) y multifase (Fe–C, Al–Si). Canvas puro, 0 dependencias.

Datos: CSV de fronteras + tabla de límites frente a ASM / IAPWS / Datchi. Se regeneran con make verify.

Fase 10–11: Al–Si calibrado por estabilidad de red (eutéctico ≈850 K) y eutectoide γ→α+Fe₃C. Siguiente (Fase 12): contraste CALPHAD/SGTE.
